Live data: the page queries the U.S. Census Bureau 2020–2024 ACS five-year API for median household income (B19013), median owner-occupied home value (B25077), owner occupancy (B25003), median year built (B25035), population, housing-age distribution (B25034), and owner-occupied values at $500,000+, $750,000+ and $1 million+ (B25075). ZIP boundary heatmaps come from Census TIGERweb. The annual ACS is authoritative but not a monthly market-price feed. ZIPs are Census ZCTAs, not exact USPS delivery boundaries. The score is a builder-targeting model, not a Census statistic.
Live market-price API options
Recommended production architecture: keep the Census API browser-side because it is public and keyless. For monthly values, listing activity, permits or parcel-level prospecting, use a scheduled serverless function so API keys remain private. Zillow Research and Redfin publish downloadable market files but do not provide a simple public browser API for this use. ATTOM and RentCast provide commercial APIs for valuations, transactions, ownership, tax and property characteristics. A serverless endpoint can normalize those feeds into one small JSON file consumed by this page.
